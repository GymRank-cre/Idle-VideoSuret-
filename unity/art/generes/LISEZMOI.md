# Visuels générés (30/10) pour Idle Sécurité

Générés avec Higgsfield (GPT Image 2.5), style « 3D cartoon jouet, brillant, couleurs saturées, contour sombre », à la manière d'Idle Lumber. **Aucun personnage dans le décor** (voulu par Sébastien) ; les portraits ne servent que dans la fenêtre Commandes.

| Fichier | Usage |
|---|---|
| `ecran-titre-9x16.jpg` (1080x1910) | **Fond de l'écran titre** (logo « IDLE SÉCURITÉ » déjà dedans, bouton « JOUER » à poser en bas, zone herbe libre) ; aussi pour les captures de la boutique |
| `icone-app-A-1024.png` | **Icône de l'app** proposée (caméra dôme, billets, tapis) ; `B` est la variante bouclier ; 1024x1024 sans transparence (App Store) |
| `diorama-cible-1.jpg`, `diorama-cible-2-gros-plan.jpg` | **Cibles de direction artistique pour la scène Unity** (UW) : à égaler en lumière, richesse, matières |
| `icones/*.png` (256x256, fond transparent) | Icônes d'interface : billet, étoile, engrenage, éclair (Vitesse), plus (Ajouter), commandes, flamme (Turbo), cadenas, caisse, caméra, camionnette, bouclier |
| `icones-planche.jpg` | Planche d'origine des 12 icônes |
| `portraits/*.png` (256x256) | 8 clients : karim, lea, marc, ines, paul, sofia, hugo, nadia (même ordre que `CLIENTS` du jeu) |

Version web : `usine-web/idle-securite-usine.html` les intègre déjà (écran titre, icônes, portraits) ; `usine-web/src/build.py` les encode dans la page.
